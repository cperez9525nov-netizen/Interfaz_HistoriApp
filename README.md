# PROYECTO DE DESARROLLO DE INTERFACES

## ¿De qué trata?

El proyecto es simple; un mapa en el que puedes viajar en el tiempo por siglos, buscando las batallas más importantes que cambiaron el rumbo de la historia.

## ¿Qué podemos ver?

En primer momento, una simple página de login, en el que podremos entrar como invitado o bien registrarnos, tanto con un correo electrónico, la cuenta de Google o la cuenta de Apple.
